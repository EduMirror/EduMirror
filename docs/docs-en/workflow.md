# Step-by-Step Walkthrough

Follow these steps to complete a simulation. Screenshots illustrate the English interface.

## Step 1: Select a scenario

At **Select Scenario**, choose a scenario card. Search by keyword or use pagination to browse more scenarios.

```{image} _static/screenshots/01-select-scenario.png
:alt: Select a scenario
:width: 100%
:align: center
```

## Step 2: Review and modify scenes

At **Modify Scenario**, select a baseline or intervention scene from the left. Review its **Call to Action** and each agent's **Default Premise** on the right.

```{image} _static/screenshots/02-edit-scenario.png
:alt: Review scene settings
:width: 100%
:align: center
```

Click **Save Changes**, then **Confirm & Continue**. Even when making no changes, read the requirements first.

## Step 3: Check agents

At **Configure Agents**, check the run scope, then review the condition, scene, and agent cards in that order.

```{image} _static/screenshots/03-configure-roles.png
:alt: Review agents by condition and scene
:width: 100%
:align: center
```

Cards summarize names, agent types, goals, and behavioral traits. An agent may appear in several scenes; one edit updates its shared settings across the scenario. Use **Edit** when needed, save, check the cards, and select **Confirm & Continue**.

## Step 4: Start the run

For a first run, choose **Original simulation only**. To compare conditions, save an intervention and choose **Original + Intervention simulation**. Choose **Intervention simulation only** to run just the intervention branches.

```{image} _static/screenshots/04-run-simulation.png
:alt: Three available run modes
:width: 100%
:align: center
```

Check the current mode and conditions displayed on your page, start the simulation, follow the live log, and select **View Results** when complete.

## Step 5: Review results

Read the overall process summary and agent-state analysis, followed by Surveyor and Rater results.

```{image} _static/screenshots/05-results-analysis.png
:alt: Review simulation results
:width: 100%
:align: center
```

Read the full process before interpreting scores, then compare the baseline and intervention conditions using the same agents and measures.

## Step 6: Generate media and revisit history

Select **Media Generation** to open the comic and video tools.

```{image} _static/screenshots/06-media-generation.png
:alt: Generate comics or videos
:width: 100%
:align: center
```

On a later visit, open a saved simulation from history to review its results, logs, and media-generation options without rerunning it.
