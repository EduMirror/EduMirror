# EduMirror User Guide

> Guide version: **1.0.0**

EduMirror is a platform for simulating and analyzing educational scenarios. Select an educational or social-behavioral scenario, review its agents and interaction settings, run a simulation, and examine the interaction process and analysis results.

## Core capabilities

| Capability | Description |
| --- | --- |
| Simulation | Multiple agents interact according to their settings, with the process recorded in event logs. |
| Intervention comparison | Compare interaction processes and outcomes across baseline and intervention conditions. |
| Needs analysis | Examine agents' core needs, need gaps, satisfaction, and actions. |
| Process and outcome analysis | Interpret results using interaction logs, process summaries, questionnaires, and behavioral ratings. |
| Simulation history | Reopen completed runs and review their conditions, logs, and analysis results. |
| Media generation | Generate comics or videos to help present the simulated interactions. |

## Reading this guide

Switch the platform to **English** to follow the English control names used here. An **agent** is a simulated participant; a **scenario** is the overall setting, while a **scene** is one episode within it. Conditions specify the baseline or intervention sequence of scenes.

Screenshots illustrate the English interface. Example results use the Celebrity Worship and Identity Formation scenario.

## Interpreting results

Simulation results support exploration and comparison. Interpret them alongside the interaction logs, scenario settings, and your research question; do not rely on an automatically generated summary alone.
